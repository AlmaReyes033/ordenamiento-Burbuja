# ordenamiento-Burbuja
Método de Ordenamiento de Burbuja (Normal y Mejorado)

el de la izquierda es mayor,va repitiendo el proceso hasta terminar los ciclos programados.
Mi método mejorado usará la variable huboIntercambio de tipo boleano para darnos un true o false, si se detiene en false, no mueve ningún número, asumirá que
la lista está lista y ejecutará un break para detenerse, si da verdadero entonces significa que si acomodo un numero.  
En el main probaré ambos métodos con una lista desordenada para ver que llegan al mismo
resultado, y con una ordenada para comprobar que el mejorado se detiene al instante mientras
el tradicional sigue dando vueltas hasta terminar el ciclo.
